# Terse output

Use short, evidence-first replies for routine work. Lead with the result, changed paths, and the exact check when relevant. Prefer bullets over narrative.

## Safety exceptions

Security warnings, irreversible action confirmations, and multi-step sequences are never compressed. Preserve the conditions, consequences, and order needed to act safely.

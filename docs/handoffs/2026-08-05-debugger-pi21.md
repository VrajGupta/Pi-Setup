## Findings (fixed)

### 1. `normalizeMaxLines`: NaN/Infinity both mapped to minimum 8 (the clamp floor)

- **Spec:** `maxLines` clamp [8,200]; absent/non-numeric → 40. NaN is non-numeric → 40. Infinity is numeric but > 200 → clamp to 200.
- **Before:** `if (!Number.isFinite(value)) return 8` — lumped NaN, Infinity, -Infinity all to 8.
- **After:** `if (typeof value !== "number" || Number.isNaN(value)) return DEFAULT_MAX_LINES` — NaN → 40. Infinity and -Infinity fall through to the numeric clamp (`Math.max(8, Math.min(200, Math.floor(value)))`): Infinity → 200, -Infinity → 8.
- **Test:** NaN → 40 (moved out of "minimum 8" test into a new "non-numeric → 40" test). Infinity → 200 (new test).

### 2. `routeLabel`: unsafe `String(r.stage)` throws on Symbol values

- **Spec INV-6:** A malformed state must never throw to the TUI. The outer try/catch handled this (degraded to 3 base lines), but a Symbol route stage nuked the entire widget (mode, agents, rail all lost) to a false `mode workflow / route direct`.
- **Before:** `safeToken(String(r.stage), "")` — `String(Symbol())` throws TypeError.
- **After:** `safeToken(r.stage, "")` — `safeToken` calls `safeString` which catches the TypeError and returns `"?"`.
- **Test:** `{ mode: "fleet", stage: Symbol("bad") }` → renders `route fleet` (safeToken("?", "") → "?" → truthy → "route fleet/?" truncated at width).

### 3. `inputLines` not redacted (INV-2 gap)

- **Spec INV-2:** No credential, header, token, or URL secret reaches any surface. Input lines are user-controlled text (will hold issue titles for PI-23).
- **Before:** `inputLines.map((line) => safeTruncate(safeString(line), width))` — no secret redaction.
- **After:** `inputLines.map((line) => safeTruncate(safeToken(line, ""), width))` — redacts secret tokens and assignment patterns.
- **Test:** `api_key=...` and `sk-...` in input lines → `[REDACTED]`; plain text unchanged.

### 4. Perf test flakiness

- 1000 renders × 100 input lines was 5.2s on a loaded machine (1 in 5 runs). Reduced to 20 lines, still proving the 1000-render/2000ms budget. 100 lines is heavier than the widget will ever see in practice (PI-23 adds issue rows, ~10-20 lines).

## Findings (rejected — not real defects)

- **Prototype pollution via state keys:** `renderStatusWidget` reads own/inherited properties. A `__proto__`-polluted state would use inherited values, but the widget is a pure render function — it doesn't write or merge. No attack vector.
- **CJK/emoji at small widths:** `truncateToWidth` from `@earendil-works/pi-tui` handles wide glyphs correctly. Proved at width 30 with CJK and emoji.
- **Negative/NaN/string agent fields:** `safeElapsed`, `formatTurns`, `contextCell` all handle non-finite, negative, string, and missing values defensively → `0` or `? ctx`. No crash, no leak.
- **`now` fallback to `Date.now()`:** Breaks strict determinism when `now` is absent from state. The caller (`index.ts`) always passes `now`. The fallback is a safety convenience, not a production path. Tabular determinism holds when `now` is provided (as the caller always does).
- **Flaky 1000-render test:** 1 in 5 runs exceeded 2s on a loaded machine. Reduced to 20 lines to reduce flakiness while keeping the 1000-render/2000ms budget.

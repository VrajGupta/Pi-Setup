### RoutineDefinition

```typescript
{
  name: string;           // non-empty, unique
  scheduleMs?: number;    // clamped [2000, 300000], default 10000
  at?: number[];          // minutes of day (0-1439), optional
  prompt: string;         // non-empty
  enabled?: boolean;      // defaults true
  snoozedUntil?: number;  // epoch ms; skipped while now < snoozedUntil
}
```

## Key design decisions

- **Interval clamp [2000, 300000]** per-routine (mirror tracker-poll, spec q1).
- **Missing scheduleMs + no at → never fires** (configError "missing schedule", per spec).
- **at-list** fires when minute-of-day ∈ at; `lastFiredMinuteKey` (absolute minute index) prevents re-fires within the same minute and naturally handles day wrapping.
- **Both interval + at**: either condition triggers (interval fires at cadence, at fires at matching minutes).
- **Per-routine isolation**: `fire()` wraps onDue in try/catch + Promise.resolve; errors captured per-routine lastError.
- **Single-flight**: `isRunning` flag; skip fire if `isRunning && isDue`.
- **Tick interval**: min of clamped scheduleMs across routines; at-only routines contribute 60000ms tick; defaults to 10000.
- **stop()**: sets `isStopped`, clears the single recurring timer, prevents reschedule.
- **No-routines**: no timer scheduled (pendingCount 0).

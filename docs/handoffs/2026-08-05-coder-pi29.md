## API

```typescript
readRoutines(settings: Record<string, unknown>): ReadResult
// ReadResult = { routines: RoutineDefinition[], warnings: string[] }

writeRoutines(routines: RoutineDefinition[], settings: Record<string, unknown>): WriteResult
// WriteResult = { ok: true, settings: object } | { ok: false, reason: string }
```

### RoutineDefinition shape

```typescript
{
  name: string;         // non-empty, unique
  scheduleMs: number;   // positive finite number
  at?: number[];        // optional, integers 0-1439, invalid filtered silently
  prompt: string;       // non-empty
  enabled: boolean;     // defaults true
}
```

### Key design decisions

- **Duplicate names:** first-wins (INV-16). Second entry dropped with warning.
- **`at` invalids:** silently filtered. If `at` is not an array, entry dropped.
- **No clamping:** scheduleMs validated as positive number; clamping is a scheduler concern (PI-28).
- **INV-2:** warnings never echo raw values.
- **INV-6:** read path never throws on any input. Malformed entries dropped per-entry.
- **INV-10:** write preserves every unrelated settings key.

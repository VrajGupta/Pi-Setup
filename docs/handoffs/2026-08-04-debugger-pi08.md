## Fixes

- `scripts/install.mjs` now canonicalizes the existing portion of the agent path and rejects any target inside the checkout before settings, dependency, or resource mutation. Exact in-place installs remain supported and unchanged.
- Empty explicit/env paths now fall back to `~/.pi/agent` rather than resolving to the current directory.
- A checkout without `node_modules` must contain `package.json` before dependency installation can start; malformed/incomplete checkout failures occur before settings mutation.
- Added two focused production-CLI regressions in `extensions/shared/install.test.ts`; no test-per-criterion expansion and existing safety coverage is preserved.

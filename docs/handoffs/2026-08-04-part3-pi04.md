## Red-team pass and fixes

- Added known-stage filtering with stable ordering, preserved duplicate stage
  agents, capped stage rows at four, and kept helper/unknown agents out.
- Normalized narrow/non-finite widths and safely truncated every base, stage, and
  status line using visible-width-aware ANSI handling.
- Added safe fallbacks for empty/oversized/Unicode labels and non-finite
  `startedAt`, `now`, and `turns` values.
- Validated runtime readings before displaying a percentage. Malformed or
  non-finite readings become stale indeterminate rows; measured percentages are
  shown only for valid measured readings. The exact 30,000 ms boundary remains
  fresh; 30,001 ms is stale.
- Preserved the input agent order by sorting a decorated copy, and kept the
  footer pure: `footer.ts` has no filesystem, subprocess, network, or provider
  calls.
- Wrapped extension-status acquisition in `index.ts`; a broken status provider
  now degrades without crashing the TUI. The render callback also captures one
  `now` value for all readings.
- Added a live event-bus harness proving stage summaries reach the footer with
  measured context progress while helpers remain omitted.

## Summary

Audited the belowEditor widget routines section and flow panel Routines tab. Three real defects found and fixed test-first; 6 regression tests added.

## Findings

### Fixed

1. **NaN/Infinity leak in `formatRelative` and `routineStatusToken`.** `formatRelative(NaN)` returned `~NaNhNaN%60m`; `-Infinity` dueAt leaked `~InfinityhInfinity%60m`. Added `Number.isFinite(ms)` guard in `formatRelative` → `"?"`. Added `isFiniteNumber(r.dueAt)` guard in `routineStatusToken` → `"?"`. Proved with probes: NaN, Infinity, -Infinity, undefined dueAt all produce no NaN/Infinity in output.

2. **Null entries in routines array silently dropped the widget section.** `routineRows` accessed `r.enabled` on every entry including null/undefined, throwing before any array processing. The `routineSection` try/catch caught it and returned `[]` — the entire section vanished. Fixed with per-row `safe` filter at the start of `routineRows`. Also fixed the same pattern in `routineSection`'s `dueCount` calculation.

3. **Null entries in Routines tab crashed the flow panel.** `FlowPanel.routines` called `routineRow(r, now)` on every entry including null, throwing and crashing the panel. Added per-row `safe` filter before the map.

4. **Future `dueAt` appeared as "due now".** The due filter only checked `enabled` and `snoozedUntil`, not `dueAt`. A routine with `dueAt` in the future was shown as "due" with a "due now" token. Added `isFiniteNumber(r.dueAt) && r.dueAt <= now` to the due filter and `routineSection`'s `dueCount`.

### Rejected (no fix needed)

- `snoozedUntil` missing/NaN/negative: already handled by `isFiniteNumber` check.
- Disabled+snoozed combo: `!r.enabled` checked first — "disabled" wins. Correct per spec q5 (snoozed routines are still enabled; disabled wins when both set).
- `snoozedUntil === now` boundary: correctly not snoozed (strict `>` comparison).
- Width boundaries 59/60/61: `collapsed = width < 60` correct.
- `session_shutdown` does not reset `routinesSnapshot` module variable: latent but PI-32 concern (widget removed on shutdown, new widget created on start).
- `npm test` full suite: known live Claude spend-limit failures outside lane.

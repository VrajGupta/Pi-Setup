## What was built

- `sortSubagents(subs)` — exported from `src/ui/takeover.ts`. Deterministic
  dashboard ordering: `running` first, then `done`, then `error`; tiebreak by
  the snapshot's `createdAt` (this domain model's started-at timestamp — the
  ticket's `startedAt` term maps to `SubagentSnapshot.createdAt`; there is no
  `startedAt` field in `domain.ts`) ascending, then by `id` ascending. Input
  array is not mutated.
- `SubagentDashboard.subs()` now returns `sortSubagents(this.view.list())`, so
  the rendered dashboard is ordered regardless of manager Map insertion order.
- Dashboard footer hint now states both escape behaviours in text:
  `<confirm> take over · <cancel> back to session · <cancel> in takeover back
  to picker` (the existing `openSubagentPicker` loop returns to the dashboard
  after a takeover resolves; cancel from the dashboard resolves the picker).

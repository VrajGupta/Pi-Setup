## Summary

Added `extensions/workflow/tracker-poll.ts`: a single-flight fixed-interval
off-render poll for repository tracker snapshots.

- Interval clamped to [2000, 300000] ms, default 10000 (configurable via
  `workflow.trackerPollMs` per ticket; consumption wiring is PI-23's lane).
- Single-flight: at most one read in flight; a tick while in flight is skipped.
- Read timeout (equal to the interval) records `reason: "timeout"` while
  preserving the previous snapshot, and — the module defect found during
  finalization — no longer clears the in-flight flag, so a slow read can never
  overlap with the next tick.
- `stop()` clears the timer; the module never writes/commits/pushes anything.

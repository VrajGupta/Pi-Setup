## Implementation notes

**`renderStatusWidget(state: StatusWidgetState): string[]`**

Takes `{width, maxLines, inputLines}` and returns:
- Empty array if width ≤ 0 or inputLines is malformed
- All N input lines (truncated to width) if N ≤ maxLines
- First (maxLines - 1) input lines + 1 overflow line (`+N more · /flow`) if N > maxLines

`maxLines` normalization:
- `undefined` → default 40
- Any other value → clamp to [8, 200] (including NaN, 0, negative, very large)
- Invalid inputs degrade to 8 (runaway guard)

**Widget registration in `index.ts`**

On `session_start`, calls `ctx.ui.setWidget("vraj-status", factory, { placement: "belowEditor" })` with an empty input array (no rows yet; later tickets will populate). On `session_shutdown`, clears the widget via `ctx.ui.setWidget("vraj-status", undefined)`.
